# Simulink Integration Guide

While PhysioCare operates as an independent web-based platform with its own lightweight kinematic engine, it can integrate with **MATLAB / Simulink** for advanced biomechanical validation, research purposes, and academic validation.

## Why Integrate with Simulink?
Simulink provides the Simscape Multibody environment, which allows for rigorous mechanical modeling of human joints. By feeding our web-based kinematic data into Simulink, clinical researchers can:
1. Validate the accuracy of our in-browser angle calculations against a rigid-body physics engine.
2. Estimate internal muscle forces and joint torques using inverse dynamics.
3. Simulate the long-term wear and tear on surgical implants (e.g., knee replacements) based on real patient movement data.

## Integration Architecture

### 1. Data Export from Web Application
The PhysioCare web application continuously tracks patient landmarks. We can export this telemetry data (time-series JSON or CSV) during a session.
- **Data Points:** Timestamps, 3D Cartesian coordinates of joints (Hip, Knee, Ankle), calculated angles, and motion quality scores.
- **Frequency:** 30 Hz.

### 2. MATLAB Data Ingestion
A MATLAB script parses the exported JSON/CSV file to create time-series objects (`timeseries`).

```matlab
% Example MATLAB Script Snippet
data = jsondecode(fileread('patient_session_001.json'));
time = data.timestamps;
kneeAngles = data.kinematics.kneeAngle;

% Create timeseries for Simulink
ts_kneeAngle = timeseries(kneeAngles, time);
```

### 3. Simulink Multibody Model
Within Simulink:
- A leg model is constructed using Simscape Multibody blocks (Rigid Transforms, Solid blocks for Femur and Tibia, and a Revolute Joint for the Knee).
- The `ts_kneeAngle` data is fed into the Revolute Joint as a motion input.
- The model is configured to compute **Inverse Dynamics**.

### 4. Output & Analysis
As the Simulink model runs using the patient's exact movement data:
- Sensors on the Revolute Joint output the **Actuation Torque** required to produce the movement.
- Joint internal reaction forces (Patellofemoral shear forces) are calculated.
- The results are plotted in the Simulation Data Inspector to identify moments of high joint stress, corroborating the "Joint Pressure & Safety Check" generated by the web app.

## Future Scope: Real-Time API
For live academic demonstrations, a local Node.js WebSocket server can be established to stream 3D coordinate data directly from the browser to a listening MATLAB UDP port, allowing Simulink to animate a 3D digital twin of the patient in real-time.
